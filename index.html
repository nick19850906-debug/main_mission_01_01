"도구에 휘둘리지 않고, 브라우저의 원리로 소통합니다."

React, Vue 등 수많은 프레임워크가 등장하지만, 브라우저가 직접 읽고 실행하는 언어는 HTML, CSS, JavaScript 단 세 가지입니다.

저는 querySelector로 DOM을 찾고, addEventListener로 이벤트를 감지하며, fetch 비동기 통신을 통해 데이터를 그려내는 웹 개발의 본질적인 동작 원리를 깊이 학습하고 있습니다. 이 탄탄한 기초가 앞으로 마주할 모든 기술 스택의 든든한 밑거름이 될 것임을 확신합니다.

시맨틱 웹 표준

의미 있는 태그를 사용하여 누구나 접근 가능하고 검색엔진에 친화적인 마크업을 지향합니다.

모바일 퍼스트 반응형

Flexbox와 Grid를 조합하여 스마트폰부터 대형 모니터까지 일관된 최상의 경험을 선사합니다.

상태 기반 렌더링

이벤트 발생 시 상태(State)를 변경하고 그에 맞춰 UI를 갱신하는 현대 웹 아키텍처를 실천합니다.

TECH STACK

제가 보유한 핵심 기술 스택

Core Foundation

HTML5

div 만능주의를 탈피하고 header, nav, section, article 등 시맨틱 태그로 정보의 위계를 설계합니다. 웹 접근성과 SEO를 철저히 고려합니다.

  • #시맨틱마크업
  • #웹접근성(a11y)
  • #SEO최적화
Layout & Styling

CSS3

CSS 커스텀 속성(변수)으로 다크모드를 구현하며, 1차원 배치는 Flexbox, 2차원 그리드는 Grid를 정확한 기준에 맞춰 채택합니다. Mobile-First 미디어 쿼리를 준수합니다.

  • #CSS변수(:root)
  • #Flexbox_vs_Grid
  • #MobileFirst
Dynamic Logic

JavaScript (ES6+)

var를 완전히 배제하고 const/let, 화살표 함수, 구조분해 할당을 다룹니다. addEventListener를 통해 브라우저 이벤트를 제어하고 DOM을 조작합니다.

  • #DOM조작
  • #화살표함수
  • #구조분해할당
Data Communication

비동기 통신 (Async/Fetch)

fetch와 async/await, try/catch를 사용하여 REST API를 호출하고, 로딩(Loading), 성공(Success), 에러(Error), 빈값(Empty)의 4가지 상태를 UI로 분기 렌더링합니다.

  • #FetchAPI
  • #AsyncAwait
  • #상태분기처리
